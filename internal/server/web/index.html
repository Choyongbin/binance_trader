Demo 비공개 WebSocket 연결 진단 (읽기 전용)

실제 Demo 인증 연결 후에만 실행할 수 있습니다. 비공개 스트림 접속을 5초간 확인하고 이벤트 종류·건수만 기록합니다. 주문은 실행하지 않습니다.

연결 성공만으로 이벤트 누락, 완전한 계정 동기화 또는 안전한 주문 가능 여부를 판단할 수 없습니다. 기존 listenKey를 다른 앱이 사용 중일 수 있으므로 강제 폐기하지 않습니다.

Demo 계정 스트림·전체 REST 동시 관측 (읽기 전용)

서명된 Demo 전체 계정 REST 조회와 비공개 WebSocket 이벤트 관측을 겹쳐 실시합니다. 최대 약 110초. 실제 주문 없음.

관측이 끝나면 WS 연결도 종료되므로 이 검사는 과거 진단입니다. WS 단절/외부 거래/기존 불완전 기록이 있으면 차단하며, 성공 결과도 연속성이나 거래 안전성을 증명하지 않습니다.

Demo 계정 상시 관측기 (개발 검증 · 읽기 전용)

실제 거래 잠금 유지. WS 연결·5분 주기 서명 REST 대조는 계정 이력의 무누락이나 주문 허가를 의미하지 않습니다. 서버 재시작 시 자동 시작되지 않으며 미종료 기록은 수동 검토가 필요합니다.

READY, continuity 확인, blocker 0건 중 어느 것도 단독으로 주문 허가를 의미하지 않습니다. 실제 side effect 직전 fresh signed preflight와 final guard가 다시 필요합니다.

시장·계정·배정지갑·execution·protection·mutation 상태를 하나의 authoritative gate로 확인합니다. READY여도 실제 주문 직전 fresh preflight와 final guard가 다시 필요합니다.

복구·상시 관측·보호 주문·회계·통합 검토의 로컬 불변 증적을 한 번에 교차 확인합니다. 거래 허가나 Binance 실시간 상태가 아닙니다.

차단 상태가 있으면 우선순위별 read-only 복구 가이드를 표시합니다. 파일 삭제·재주문·자동 unlock은 수행하지 않습니다.

CRITICAL blocker별 sealed read-only incident packet을 생성합니다. 원본 private event나 인증정보는 포함하지 않습니다.

restart/gap/recovery/protection/accounting/execution 증적을 시간순으로 재구성합니다.
